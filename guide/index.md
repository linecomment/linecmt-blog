# 关于本站

本站基于 [VitePress](https://vitepress.dev/) 搭建，用于整理个人学习笔记、工具备忘与阅读记录。

## 目录说明

| 区域 | 说明 |
|------|------|
| **指南** | 站点使用方式、Markdown 与 VitePress 示例 |
| **知识笔记** | 按主题分类的长期积累（开发、工具、阅读、实验） |

## 写作约定

- 新文章按主题放入 `notes` 下对应子目录；快速草稿可放在「实验与草稿」。
- 需要稳定排序时，可在 frontmatter 中设置 `order` 数字（越小越靠前）。
- 文件名建议使用有意义的英文或拼音，便于链接与检索。

## 本地开发

在项目根目录执行：

```bash
pnpm docs:dev
```

构建静态站点：

```bash
pnpm docs:build
```
